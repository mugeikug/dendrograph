ブラケット記法の書き方

樹形図はすべて、角括弧を使ったテキスト入力から自動生成されます。ここでは、その書き方を一通り説明します。

基本は「角括弧の中に、ラベル、そして子ノード(さらに角括弧か、単語)を並べる」だけです。以下の項目は、必要になったときに1つずつ参照すれば十分です。最初から全部覚える必要はありません。

基本の形

[ラベル 子1 子2 ...] の繰り返しで木を組み立てます。子は、さらに角括弧で囲めば枝分かれし、そのまま単語を書けば葉(それ以上分岐しないノード)になります。スペースで区切られた単語は、それぞれ別の子として扱われます。

[S [NP the dog] [VP runs]]
構造S の下に NP(the, dog の親)と VP(runs の親)が並ぶ木になります。

ラベルの省略

[ の直後にスペースを入れると、そのノードにはラベルを付けず、続く単語すべてを子として扱います。

[ a b]
構造ラベルなしのノードの下に、a と b が並びます。

複数語のラベル・空白を含む語

スペースを含む1つのまとまりをラベルや葉として書きたい場合は、{ } で囲みます。囲まないと、スペースのところで別々の子に分かれてしまいます。

[NP {the very old man}]
構造NP の下に、"the very old man" という1つの葉ができます。

三角ノード(未展開の句)

ラベルの直後に △(または ▲ / !)を付けると、内部構造を省略した三角形で描画されます。三角形の中身(yield)は、続けて書いた単語列がそのまま使われます。

[NP△ the very old man]
構造NP から三角形が下に伸び、その下に "the very old man" と表示されます。

上付き・下付き文字

_{...} で下付き、^{...} で上付きになります。1文字だけなら中括弧を省略して _1 のようにも書けます。

[NP_{1} [D the] [N man]] [what^*]
結果NP1、what* のように表示されます。

イタリック・ボールド

\it{...} でイタリック体、\bf{...} でボールド体になります。$で囲む必要はなく、通常のラベルの中にそのまま書けます(上付き・下付きとの組み合わせには対応していません)。

[NP \it{John}] [VP \bf{loves}]
結果John、loves のように表示されます。

移動の矢印

ラベルの末尾に ~タグ を付けると、同じタグを持つノードが木の中にちょうど2つあるとき、その間に自動で曲線矢印が引かれます(深い方から浅い方へ)。三角マーカーと組み合わせる場合は ラベル△~タグ の順に書きます。タグにスペースを含めたいときは ~{...} のように中括弧で囲みます。同じタグを持つノードが3つ以上ある場合も、深い順に自動で連鎖して(継続循環移動のように)矢印を引きます。

[CP What~1 [C' C [IP you did [VP see t~1]]]]
構造"t" から "What" へ向かう矢印が自動で引かれます。矢印はプレビュー上でドラッグして曲がり方を調整できます。

矢印・連結線のスタイル(上級者向け)

木の後ろに \linestyle[形状, to側マーカー, from側マーカー, 太さ, 線種]{タグ} と書くと、そのタグの矢印/連結線の見た目を個別に指定できます。指定が無いタグは今まで通りの見た目(曲線・先行詞側に矢印・実線・枝と同じ太さ)のままです。

  • 形状: curve(曲線の矢印) / square(Agreeなどを示す直角の「コ」の字型連結線)
  • マーカー: 浅い方(to側)・深い方(from側)それぞれ独立に arrow / none
  • 太さ: 0.5pt のようにpt単位
  • 線種: solid / dashed / dotted
[TP [T T~2] [vP [DP John~2] [v' v [VP loves Mary]]]] \linestyle[square, none, none, 1pt, solid]{2}
構造TとDPの間に、矢印のない直角の連結線が引かれます。連結線の折れ曲がり位置はドラッグで調整できます。

記号自体を書きたいとき

~ や $ は特別な意味を持つ記号なので、そのまま文字として使いたい場合は直前に \ を付けます(\~、\$)。

数式・素性構造(上級者向け)

ラベルの一部を $...$(インライン)または $$...$$(ディスプレイ)で囲むと、その部分だけが数式として組版されます。Wordに挿入した際も、その場で編集できる本物のWord数式になります。

(La)TeXが分かる方へ (La)TeXの数式環境相当の記法(に準じたもの)がそのまま使えます。英字は言語学の表記慣習に合わせて既定でイタリックになりません。素性構造なら $\begin{bmatrix} \text{CASE} & \text{nom} \\ \text{PERS} & 3 \end{bmatrix}$ のように書けます。
知らない方へ この機能は使わなくても、上記の書き方だけで通常の樹形図は問題なく作れます。無理に使う必要はありません。

その他の操作

記法以外の基本操作です。

  • プレビュー上のノードはドラッグで位置を微調整できます(ダブルクリックでそのノードだけリセット)
  • 「位置をすべてリセット」でまとめて元に戻せます
  • 「横 / 縦」の%指定で、樹形図全体の縦横比だけを変えられます(文字の大きさは変わりません)
  • 「枝の太さ」欄(pt単位)で、樹形図の枝全体の太さを変更できます
  • 「Wordに挿入」で編集可能な図形として挿入、「forestコードをコピー」でLaTeX(forestパッケージ)コードを取得できます
入力にエラーが出たら: 角括弧の対応([ と ] の数)と、{ } の対応が取れているか、まずは確認してみてください。
